A2A Kite Coordination Extension

Release candidate — not yet v1.0.0. The complete accepted outcome path and a seller-consented refund path have executed against a live Runtime, including real escrow, settlement, proof-chain reads and buyer balance restoration; the accepted path also covered the deployed reference seller and autonomous delivery. Strict conformance remains open because the suite's 36 live cases have no driver yet (spec §9.1), so the bundle is interoperable on the validated paths but not fully conformant or frozen.

A versioned extension to the A2A protocol that lets buyer and seller agents form and execute agreements through the Kite Coordination Engine: typed, signed workflow commands; two-signature agreement over one termsHash; runtime-signed transition receipts; party-readable transition-proof chains. (Independently verifiable audit proof packages are a later addition — spec §9.2.) No A2A fork, no Kite SDK required.
